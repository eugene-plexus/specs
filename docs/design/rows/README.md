# Row designs

One build design per roadmap row, written by the orchestrator (or drafted for
it and reviewed) before the row starts. Each row's GitHub issue links its
design here. The design names what the row delivers, the design itself, the
repositories and files, the test that fails before the change, the acceptance
for a high-risk row, the files other lanes own, and the open calls (which also
go in Troy's calls file).

The roadmap is [`../roadmap.md`](../roadmap.md); the row data is
[`../roadmap-rows.json`](../roadmap-rows.json).
