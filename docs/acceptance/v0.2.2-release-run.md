# v0.2.2 release run

Troy approved stable publication as v0.2.2 on 2026-10-15 after the Cline,
Strata and Update all work. The [harness record](v0.2.2-harness-run.md) holds
the six real CLI tool loops, protocol checks, component tests and two-node
Update all restart acceptance. The owner also confirmed Cline connected
successfully after updating the container.

## Clean installation to a real reply

Both packaged installers passed `scripts/s10-acceptance.py` on 2026-10-15.
Each fresh prefix installed Python 3.12 and all seven packages, opened the
shipped UI, completed setup and sign-in, acquired the engine, launched the
model, returned a browser reply and answered a separate keyed curl request.

| Target | Installer elapsed | Install to first visible token | Result |
|---|---:|---:|---|
| Windows 11 | 18.1 s | 65.0 s | Passed; live service and account environment unchanged |
| Ubuntu under WSL2 | 11.8 s | 80.0 s | Passed |

These were CPU fixtures with accelerators hidden, isolated ports and a
seeded 5,335,291,936-byte Gemma 4 E4B Q4_K_M model. They test packaged
installation and real inference, not a timed model download or GPU support.
The instrument removed ambient `EUGENE_PLEXUS_*` variables and stopped its
own processes. No live node was updated. Windows evidence remains under
`C:/Users/troyc/AppData/Local/Temp/ep-v022-win-codex/`, with both target summaries
in `docs/private/codex-v022-*.log`. The WSL fixture used
`/tmp/ep-v022-wsl-codex/`; its temporary directory was cleared when that WSL
instance stopped after the successful run. Windows post-install inspection
also verified all seven installed commit stamps and all 264 shipped UI files
against the stable manifest and build.
