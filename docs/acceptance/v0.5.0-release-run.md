## Untested paths and limits

- **The root container upgrade** (Troy's NAS case) was not run here; this
  machine has no Docker. Release qualification and the container workflow run
  Compose, installed-Workbench and recovery acceptance on the versioned image,
  not an upgrade of a v0.2.3 container volume.
- A root with standbys and workers upgraded in order, and mixed-version
  refusal, were not exercised in a packaged install; U3's record covers the
  refusal with development code.
- Windows `-Update` and the Windows service/tray update, macOS packaged install,
  native Linux unattended boot, any GPU in a packaged install, Intel Arc, two
  physical cards and the container on a passed-through NVIDIA card.
- The second person did not sign in after the upgrade; only their directory
  entry was checked. Going back to v0.2.3 by restoring Workbench's copy was
  not tried.
- Live Google and Microsoft sign-in; a real Claude Code, Codex or Open WebUI
  connected to Workbench's MCP server.
- Strata and MLX remain experimental; Strata's native image inference is
  unvalidated.
- Feature limits are in the release notes, [v0.3.0](../releases/v0.3.0.md).
