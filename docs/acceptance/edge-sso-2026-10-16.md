# Edge: People directory and external sign-in

Published source, distribution builds and installer pins on 2026-10-16 at Troy's
request. The container workflow publishes the updated `edge` image only after
its Compose, Workbench installation and recovery checks pass. This record does
not claim that asynchronous CI or the image upload has completed.

No stable release tag or running installation was changed.

## Included changes

- Searchable, paginated People directory, dedicated account pages, visible
  permission sections and separate account actions.
- Google, Microsoft and generic OpenID Connect provider setup; explicit links
  to existing members through one-use invitations, without email-based merging.
- Shared browser sign-in for Workbench and delegated administration, account
  connections/session visibility, revocation, and local password recovery.
- Isolated sign-in cookies in the agent proxy and canonical token validation
  across the Python services.

Behavior and limits are recorded in the
[People acceptance](people-directory-2026-10-16.md) and
[U4 acceptance](u4-sso-2026-10-16.md). Provider registration is still required;
the integration run used a local OIDC issuer with real RSA signatures, not a
live Google or Microsoft account.
