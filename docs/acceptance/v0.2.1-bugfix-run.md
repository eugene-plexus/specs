# v0.2.1 bug fixes — 2026-10-14

This is the incremental bug-fix record. Release candidate acceptance is pending.

## Replicated log (control#9)

Control `4710ce8` truncates a failed append to its previous byte boundary and
syncs that rollback. If rollback fails, subsequent writes, replication reads
and snapshots refuse until restart. Public-address policy fixtures no longer
run the node poller.

Nine new regression cases failed before the fix: partial write, flush, close
and sync failures on both empty and existing logs, plus a failed rollback.
The tests check memory, subsequent appends and replay after restart. Full
Windows suite: **526 passed, 2 POSIX-only skips**. The address-policy suite
passed separately after disabling its poller (11 tests). Ruff lint/format,
mypy and gitleaks on the staged checkout passed.

## Idle upstream connections (inference-driver#9)

Inference-driver `e035dee`, gateway `8f1c3c0`, tool-driver `f46d0bb` set a
1.5-second idle expiry in their HTTP client factories. Explicit caller limits
are preserved. This reduces races with upstream idle close deadlines; it
does not guarantee a connection cannot close, and does not replay a request
whose outcome is unknown.

In each repository, four regression cases failed before the fix. Real
loopback HTTP sockets prove reuse after one second and replacement after
1.6 seconds idle; only HTTP/1.1's idle clock is advanced, without sleeps.
The synchronous factory and explicit limits are checked too.

Full Windows suites: inference-driver **1,642 passed, 5 skipped**; gateway
**1,990 passed, 1 skipped**; tool-driver **161 passed, 1 skipped**. Ruff
lint/format, mypy and staged-tree gitleaks passed in each repository.

`scripts/p5-videos-acceptance.py`, isolated ports/state with the OpenAI 3.20.0
SDK and fixture upstreams: **8 PASS**, including submit/poll/download and a
gateway restart. No live provider call was made. The first launch stopped
before testing because its interpreter lacked the SDK; setting
`EP_SDK_PYTHON` to the existing SDK environment resolved it.

## Gateway routing and errors (gateway#10–#16)

Gateway `775600a` rejects unknown embedding fields and incompatible first
alias targets, reports model ownership from backend locality, exempts model
loading from circuit failures, permits replica recovery for confirmed-local
embedding/rerank reads, and names observed key-policy failures. Hosted or
unknown read targets and timeouts retain their no-retry behavior.

Inference-driver `c6745cb` emits `#backend-loading` and treats absent, null
and empty OpenRouter parameter lists as unknown, including the basic token
cap required by Messages. Regression cases failed before each product fix.
The full suites passed: gateway **2,037 passed, 1 skipped**; driver **1,642
passed, 5 skipped**. The first gateway run exposed a disconnect fixture
passing a chat body to the embeddings route; correcting its request body
preserved its cancellation assertion. Ruff lint/format and mypy passed.

The expanded `tools-assumed-acceptance.py` used isolated loopback upstream
fixtures, real driver processes and a real authenticated gateway:

- Unknown versus explicitly unsupported OpenRouter capabilities: **134
  served, 20 refused**, through Chat, Messages and Responses, plus **76
  alias requests**; both checks passed.
- Loading: **four refusals followed by immediate recovery**, whole and
  streamed; passed. Disabling either the loading exemption or unknown-listing
  fix made its acceptance fail. Exact original file bytes were restored.

Gateway#16 was already handled by the public wire adapters. Four added
regression cases pass for zero/one/two draft-search rounds, Unicode citation
spans and Responses message-item offsets. Removing Chat's existing paragraph
separator made two cases fail. Workbench's re-anchoring remains unchanged.

Initial CI on the keep-alive commits caught missing platform-source and
vendoring metadata updates. Specs `71442dd` now holds the HTTP helper policy;
the three consumers were regenerated. Driver/gateway above and tool-driver
`f5dc64a` pass the offline integrity check. Staged-tree gitleaks passed.
