This is the incremental bug-fix record. Release candidate acceptance is pending.

## Replicated log (control#9)

Control `4710ce8` truncates a failed append to its previous byte boundary and
syncs that rollback. If rollback fails, subsequent writes, replication reads
and snapshots refuse until restart. Public-address policy fixtures no longer
run the node poller.

Nine new regression cases failed before the fix: partial write, flush, close
and sync failures on both empty and existing logs, plus a failed rollback.
The tests check memory, subsequent appends and replay after restart. Full
Windows suite: **526 passed, 2 POSIX-only skips**. The address-policy suite
passed separately after disabling its poller (11 tests). Ruff lint/format,
mypy and gitleaks on the staged checkout passed.

## Idle upstream connections (inference-driver#9)

Inference-driver `e035dee`, gateway `8f1c3c0`, tool-driver `f46d0bb` set a
1.5-second idle expiry in their HTTP client factories. Explicit caller limits
are preserved. This reduces races with upstream idle close deadlines; it
does not guarantee a connection cannot close, and does not replay a request
whose outcome is unknown.

In each repository, four regression cases failed before the fix. Real
loopback HTTP sockets prove reuse after one second and replacement after
1.6 seconds idle; only HTTP/1.1's idle clock is advanced, without sleeps.
The synchronous factory and explicit limits are checked too.

Full Windows suites: inference-driver **1,642 passed, 5 skipped**; gateway
**1,990 passed, 1 skipped**; tool-driver **161 passed, 1 skipped**. Ruff
lint/format, mypy and staged-tree gitleaks passed in each repository.

`scripts/p5-videos-acceptance.py`, isolated ports/state with the OpenAI 3.20.0
SDK and fixture upstreams: **8 PASS**, including submit/poll/download and a
gateway restart. No live provider call was made. The first launch stopped
before testing because its interpreter lacked the SDK; setting
`EP_SDK_PYTHON` to the existing SDK environment resolved it.

## Engine shutdown and Strata readiness (agent#13 and #15)

Agent `0840e04` snapshots descendant process identities before a stop or
restart, waits for them after the launcher exits, and kills lingering
descendants after 30 seconds. A further five-second bound refuses to claim
success if they remain alive. PID reuse is checked by psutil. The supervisor
does not let inherited stdout pipes hide parent exit, launch a replacement
before the drain, or report stopped before removing the runtime record.

Strata refuses to launch onto an occupied port, naming the observed holder,
and readiness requires a positive loaded context. The original warm-cache
report was not reproduced with a real model. Inspection of the pinned upstream
server shows initial service creation follows its blocking model load;
an older listener was a plausible explanation, not a proven original cause.
The new occupied-port and zero-context regressions failed before these guards.

Stop/restart regressions with real process trees failed against the original
supervisor while the child remained alive. Four tree tests cover graceful
drain, replacement, forced kill with inherited stdout, and runtime tracking.
The focused lifecycle suite passed **126 tests**; after the final cancellation
and restart guards, **29 supervisor/tree tests** passed. Full Windows suite:
**2,538 passed, 20 skipped**. Ruff lint/format, mypy on Windows and Linux
settings, vendored integrity and staged-tree gitleaks passed.

`runtime-stop-acceptance.py`: **2 PASS**, real authenticated agent API,
isolated ports/state and a fixture native child held after its launcher exits.
The first instrument checked before launcher exit and failed to detect a
disabled drain. The corrected instrument waits for launcher exit and the
output reader's drain; it detects disabled descendant tracking and the
disabled port guard. The final recorded run passed with both fixes restored.
The fixture uses `autoDriver:false` to keep every service on explicitly
allocated ports. Temporary trees were retained for logs.

`strata-protocol-check.py` against the installed pinned upstream server's mock
engine: readiness, whole response and **28 streaming frames passed**. No GPU
model load was performed. The release lock adds psutil and the already-landed
Workbench rich-content dependencies missing from its previous resolution.
