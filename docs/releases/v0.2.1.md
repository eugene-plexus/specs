# Eugene Plexus v0.2.1

Workbench gains rich answers and saved interactive previews. This release also
fixes model startup, downloads, routing and settings recovery.

Start with the [installation guide](https://eugeneplexus.com/install/).
When updating several machines, update the root first, then the other machines.

## Rich content in Workbench

- **Equations and footnotes.** Inline and display math render in answers, and
  footnote links move to the right note and back. Copy and Markdown export keep
  the source.
- **Diagrams.** Mermaid diagrams render inside answers, with their source
  available when you want it. Invalid or oversized diagrams keep a readable
  explanation and source fallback.
- **Media and files from tools.** Images, audio, video and file cards stay with
  the answer, including after reconnecting or selecting an earlier version.
- **Sources, tables and charts.** Follow a citation to its source or document
  passage. Structured tool results can appear as tables and charts.
- **Saved artifacts.** Generated Markdown, SVG, HTML and React previews keep
  their source and revisions. Open, copy or download them from the answer.
- **Previews in place.** Interactive previews run when they come into view.
  You can stop one or turn automatic previews off. They run inside an isolated
  frame; a stuck preview is stopped without losing the chat.

## Models and inference

- Idle upstream connections are retired sooner, reducing failed requests when
  a backend closes an unused connection.
- Unknown OpenRouter capability listings no longer make ordinary requests
  appear unsupported.
- A model still loading no longer counts as a circuit failure. Embedding and
  result-sorting requests can recover through another confirmed local replica
  when the first is unavailable.
- Invalid embedding fields and incompatible alias targets are refused with a
  useful explanation. Model ownership reflects the backend's locality, and
  key-policy errors name the cause Eugene observed.
- Stopping a runtime waits for the processes it started before allowing a new
  launch. Strata cannot borrow an old server's ready response, and Linux can
  restart it while old connections finish closing.
- Run keeps vLLM's selected context size in its saved profile and launch flags.
- Managed Strata models are recognized as local, so Workbench's local-only
  memory setting works with them.

## Library, settings and console

- Discover recognizes Kev decision checkpoints and downloads their complete
  folder, including the adapter and head.
- Result-sorting GGUFs with classifier tensors, including the affected BGE
  files, are recognized automatically even when pooling metadata is absent.
- Unreadable Library settings report the observed error. Repairing them keeps
  a backup first and refuses the write if that backup cannot be made.
- Library and Job Site errors keep full filesystem paths in logs instead of
  exposing them in public responses.
- A failed control-log append is rolled back before another append. If that
  rollback fails, the process refuses further log operations until restart.
- Completed Run and Add Backend actions link to **Backends**. Strata's text
  correctly says that tools and structured output work.
- Workbench's empty folder list points owners to **Toolbox → Tools → Folders**
  to grant an existing folder.

The release also repairs timing-sensitive tests and the document and memory
sabotage checks used to keep updates reliable.

## Distribution

The release installers pin every component. Workbench and Open WebUI use the
versions in the agent's app catalogue. Python runtime and build dependencies
are locked by version and hash. The Python patch version, bootstrap uv,
engine downloads and models are outside that lock.

Strata remains experimental. Its protocol and lifecycle fixes were checked
with a stand-in server; this release run does not claim a new full-size Strata
model load.
