# Eugene Plexus v0.2.2

This release fixes client failures found while connecting Cline, Hermes Agent
and OpenClaw to Strata, and adds one Update all action for machines and their
installed apps, including Workbench.

Versioned Windows and POSIX installers, a component manifest and checksums are
available in the [GitHub release](https://github.com/eugene-plexus/specs/releases/tag/v0.2.2).
The Linux amd64 container is `ghcr.io/eugene-plexus/control-plane:v0.2.2`.
See the [installation guide](https://eugeneplexus.com/install/),
[harness acceptance](../acceptance/v0.2.2-harness-run.md) and
[packaged release checks](../acceptance/v0.2.2-release-run.md).

## Client compatibility

- Reasoning effort no longer blocks a request when a backend does not support
  it. Eugene omits the unsupported hint and reports it in the ignored-settings
  header. Supporting backends receive it unchanged.
- Hermes tool loops can send the assistant's earlier thinking as `reasoning`
  or `reasoning_content`. Eugene preserves it for the next model turn.
- The Responses and Messages endpoints carry effort controls to supporting
  backends. Messages `thinking.type: disabled` takes precedence over effort.
- The OpenClaw setup recipe enables streamed usage reporting and effort
  compatibility, and explains how to enable thinking controls for a reasoning
  model.

## Strata

- Strata's reasoning support is correctly advertised. Qwen Flash Next can use
  its native effort controls, including disabling thinking.
- Driver thinking defaults use Strata's native controls. An explicit request
  can override the configured default.
- Caller stop strings are honored in streaming and whole-response requests.
- Optional Strata batching is preserved, and capacity comes from the running
  server's reported concurrency. Existing single-request configurations stay
  at one slot.

## Remote access

Access setup offers **Allow inference from any network, with an API key**,
including connections through Cloudflare. Private-network access remains the
default. This option changes inference access only; console and node-network
rules are separate.

## Update all

Machines → Versions gains **Update all** for a multi-node install. One
confirmation updates the active root first, then workers on their chosen
channels, and their installed catalogue apps, including Workbench. Progress
survives closing the page or restarting the console's agent.

Containers still use their host's update controls. If the root needs that
manual update, workers wait. Offline machines, failed updates and manual
steps are shown individually. Update the root once to get this button; existing
workers can then use their existing remote-update endpoints.

The release passed actual Cline CLI, Hermes Agent and OpenClaw file-editing
tasks through Eugene and a real Strata model. See the acceptance record for
versions, exact settings and deployment limits. Update the root/control-plane
container first, then inference nodes: the driver fix runs on the machine
hosting the model.

Strata remains experimental. The CLI checks and the owner's successful Cline
connection do not establish support for every harness feature or deployment.
Update all was tested with real enrolled nodes and restart recovery; its
installer and app-update boundaries were simulated. Individual system updates
and packaged installations have separate release checks.
